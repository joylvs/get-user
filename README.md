# Get User

Projeto desenvolvido para praticar **Node.js, APIs e requisições HTTP**.

A aplicação possui um servidor que disponibiliza endpoints para usuários e produtos, enquanto o frontend utiliza `fetch()` para consumir e exibir os dados.

## Tecnologias

* JavaScript
* Node.js
* HTML
* Fetch API
* JSON

## Como executar

```bash
git clone https://github.com/joylvs/get-user.git
cd get-user
node server.js
```

Depois, abra o `index.html` no navegador e consulte:

```text
/users
/products
```

## Objetivo

Praticar conceitos de **servidores, APIs, requisições HTTP e integração entre frontend e backend**.
